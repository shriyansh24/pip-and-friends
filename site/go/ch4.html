PART 1 · SIZED JARSInteger types and their ranges

1

Last chapter you built boxes, and every box had a type. Today: number boxes come in sizes.

Scoot says: I count letters, miles, stamps and coins. Some numbers are tiny. Some are huge.

Scoot says: Go lets me pick a box the right size for each one. Let's see what sizes there are, and what happens when a box gets too full.

Picture: Scoot points ahead, a letter in hand.

2

Think of number types as jars. Each jar is a row of tiny on/off switches called bits. More switches, bigger numbers.

CUP8 switches-128 to 127
MUG16 switches-32,768 to 32,767
JUG32 switchesabout ±2.1 billion
BUCKET64 switchesabout ±9.2 quintillion

Scoot says: The number in the name is the number of switches: int8 has 8, int64 has 64. A bit is one switch, and 8 bits make a byte.

The u in uint8 means unsigned: no minus sign. An int8 and a uint8 both have 8 switches, so both have exactly 256 settings. They just use them differently.

    

      
int8
negativespositives
-1280127

      
uint8
only zero and positives
0128255

    

    

      
SIGNEDint8 int16 int32 int64 int
Half the settings are for negative numbers. Use these for anything that can drop below zero: temperatures, scores, money owed.

      
UNSIGNEDuint8 uint16 uint32 uint64 uint
No negatives, so the top doubles. Useful for raw data, like the bytes of a file or the red, green and blue of a pixel (0 to 255 each).

    PART 4 · WOBBLY JELLYFloats, money and the math package
    

  
    
    23
    
    Numbers with a decimal point are floats (short for "floating-point numbers"). Go's everyday float is float64. Our float creature is the jelly: soft, handy, and a tiny bit wobbly.
    
    jelly.go
    
    
    
    
    
    
      
      
    Scoot says: One third can't be written exactly in decimal: 0.333 goes on forever. A float stops after about 16 digits. Here, times 3, it happens to round back to exactly 1. Not every sum is that lucky.
    
    
    
    
    Picture: a green jelly creature labelled 0.333 wobbles gently.
    
  
    

  
    
  

  
    
    24
    
    Why can't a computer store 0.1? Because its switches count in twos, not tens.
    
    
    
      
    Decimal (tens): 1 ÷ 3 = 0.33333333333333333… never ends
    
      
    Binary (twos): 1 ÷ 10 = 0.0001100110011001100… never ends
    
      
    ✂ a float64 keeps 53 binary digits, then rounds
    
    
    
    point3.go
    
    
    
    
    
    
      
      
    
        
    Scoot says: So 0.1 is stored as a number a tiny bit off. Same for 0.2. Add them, and the two tiny errors show up in the 17th digit.
    
        
    Scoot says: Constants are different: the Compiler works them out exactly, with no switches at all. Constants are exact. Variables wobble. And never test floats with ==.
    
      
    
    
    
    
    Picture: the jelly, labelled 0.30000000000000004, wobbles with its mouth open.
    
  
    

  
    
    25
    
    There is a smaller jelly too: float32. Half the switches, about 7 good digits instead of about 16.
    
    float32.go
    
    
    
    
    
      
      
    1. fmt.Println(small, big)
      Both print 0.1: Go prints the shortest text that turns back into the same stored number.
      2. 
      
    2. float64(small)
      Pour the float32 into a float64 and its wobble shows: 0.10000000149011612.
      3. 
      
    3. count+1 == count
      A float32 runs out of digits above 16,777,216, so adding 1 changes nothing: true.
      4. 
    
    
    
    Like int, float64 is the default: x := 2.5 makes one. Use float32 only with a reason (some graphics code does). Go also has complex64 and complex128 for complex numbers, which you won't need in this book.

    43
    
      What you learned in Chapter 4
      
    
        
      
      • PICK THE RIGHT JARint8 to int64, uint8 to uint64, byte, rune. When in doubt: plain int and float64.
        • 
      
      • DIFFERENT JARS NEED A FUNNELfloat64(x), int(f): a copy in a new type. int() chops toward zero. Funnel first, then divide.
        • 
      
      • JARS DON'T WARN. THEY WRAP.Overflow at run time rolls over like an odometer: 255 + 1 is 0 in a uint8. Constants that don't fit are compile errors.
        • 
      
      • CONSTANTS ARE EXACT. VARIABLES WOBBLE.Floats round: 0.1 + 0.2 in variables is 0.30000000000000004. Never compare floats with ==. Count coins, not jelly.
        • 
      
      • EVERY % IS A BLANKPrintf fills blanks left to right: %v %d %s %q %f %.2f %x %t %T, widths like %5d %-5d %05d, and \n for a new line.
        •

    Under the hood: switches, two's complement and floating point
    
      
      
      How a signed jar stores negatives
      
      
      Go stores signed integers in two's complement, the scheme every modern CPU uses. In 8 switches, the left switch is worth −128 instead of +128; the others are worth 64, 32, 16, 8, 4, 2 and 1, exactly as in a uint8. So 01111111 is 127, 10000000 is −128, and 11111111 is −128 + 127 = −1. Adding 1 to 127 is the same switch-flipping as adding 1 to 127 in a uint8 (giving 10000000); only the reading of the left switch differs. That's why one CPU instruction can add both kinds, and why both kinds wrap.
      
      
      The Go specification makes this behaviour a promise: for unsigned integers, + - * << are computed modulo 2n (n is the number of bits), and signed integers wrap in two's complement. Overflow is never undefined behaviour in Go, unlike in C and C++, and it never panics.
      
      
      Converting between integer sizes
      
      
      Converting to a smaller size keeps the lowest bits (that's uint8(300) giving 44). Converting a signed value to a bigger size copies the sign switch leftwards, so −56 stays −56 in an int64. Converting a float to an integer drops the fraction, toward zero; if the whole part doesn't fit the target type, the result depends on the machine, so check the range first.
      
      
      Inside a float64
      
      
      A float64 uses its 64 switches as 1 sign bit, 11 exponent bits (where the point "floats" to) and 52 fraction bits, plus one implied bit: 53 binary digits of precision, about 15 to 17 decimal digits. This layout is the IEEE 754 standard, shared by almost every language, which is why 0.1 + 0.2 prints 0.30000000000000004 in many of them. Whole numbers are exact up to 253 (9,007,199,254,740,992); panel 15 showed what happens one past it.
      
      
      Constants live in a different world
      
      
      The specification says numeric constants "represent exact values of arbitrary precision and do not overflow", and requires compilers to keep at least 256 bits for integer constants. Only when a constant is stored in a variable, passed to a function, or converted, does it have to fit a real jar. That's why 0.1 + 0.2 as constants is exactly 0.3, and why math.MaxUint64 fails only when Println needs it as an int.
      
      
      How Printf rounds
      
      
      %.0f rounds a value that sits exactly halfway to the nearest even digit, while math.Round always rounds halves away from zero. math.RoundToEven does what %.0f does.

    In real programs: which number types real Go code uses
    
      
      
        
        
      • int everywhere. Counts, lengths, positions and loop counters are int in the standard library. You'll see that from chapter 6 on.
        • 
        
      • int64 for money and time. Payment systems store amounts as whole cents (or smaller units) in integers. Go's own time.Duration is an int64 counting nanoseconds.
        • 
        
      • byte for raw data. Files, network messages and images arrive as sequences of bytes. A pixel's red, green and blue are often one uint8 each, 0 to 255.
        • 
        
      • float64 for measurements. Distances, temperatures, averages, science. float32 appears where memory matters, such as graphics and machine learning.
        • 
        
      • Sized types at the edges. When a file format or a network protocol says "a 32-bit unsigned number", code uses uint32 exactly. Inside the program, values are often converted to int.
        • 
        
      • Sprintf for messages, Printf for tables. Log lines, file names and error messages are built with Sprintf and Errorf. Command-line tools line up columns with widths, like the receipt.
        • 
        
      • Overflow checks where it matters. Code that adds untrusted numbers checks against math.MaxInt64 first, or uses the math/big package, whose integers grow as large as needed.
        • 
      
      
    
      
  
      

  
      
    Common wrong ideas
    
      
      
        
        
      • "int and int64 are the same on my computer, so they mix." Same size, different types. Go always wants a conversion (panel 11).
        • 
        
      • "int(3.99) rounds to 4." It chops: 3. And int(-3.99) is −3. Use math.Round first.
        • 
        
      • "float64(a / b) gives the exact average." The division already happened in whole numbers. Convert each side first.
        • 
        
      • "Overflow crashes the program." In Go it wraps silently at run time. Only constants are checked, by the Compiler.
        • 
        
      • "Unsigned is safer for things that can't be negative." One subtraction too many wraps to a huge number (0 − 1 gave 18446744073709551615). Plain int would have shown −1, which is easier to spot.
        • 
        
      • "0.1 + 0.2 == 0.3 is true." Not for float variables. Compare with a small tolerance instead, using math.Abs(a-b) < 1e-9, once you know if (chapter 5).
        • 
        
      • "%.2f fixes the float." It only changes what is printed. The stored value still wobbles.
        • 
        
      • "Printf adds a newline." Only Println does. Printf prints exactly the form.
        • 
        
      • "A wrong verb is a compile error." It compiles and prints a %! jam at run time. Run go vet.
        • 
        
      • "010 is ten." A leading 0 makes it octal (base 8): eight! Write 0o10 if you mean octal, and plain 10 if you mean ten.
        • 
      
      
      
      octal.go
      Also: 1_000_000 may use underscores to group digits, 0xff is hex and 0b1010 is binary. All four are just ways to write an int.

    Words from this chapter
    
      
      
      
        
      bit
      One on/off switch: the smallest piece of computer memory. 0 or 1.
      
        
      byte
      8 bits. Also Go's nickname for uint8.
      
        
      integer type
      A type for whole numbers: int, int8, int16, int32, int64 and the uint versions.
      
        
      signed / unsigned
      Signed types hold negatives and positives. Unsigned (u) types hold only zero and positives, up to about twice as high.
      
        
      range
      The smallest and biggest values a type can hold, like −128 to 127 for int8.
      
        
      alias (nickname)
      A second name for the same type: byte is uint8, rune is int32.
      
        
      rune
      Go's nickname for int32, used for character codes (chapter 11).
      
        
      float / floating-point
      A number with a fractional part, stored approximately: float64 (default) or float32.
      
        
      conversion
      Writing T(x) to make a new value of type T from x, like float64(n).
      
        
      truncation
      Chopping off the fraction, toward zero. What int() does to a float.
      
        
      mismatched types
      The Compiler's complaint when an operation mixes two different types without a conversion.
      
        
      argument
      A value handed to a function inside its parentheses.
      
        
      overflow
      A value too big (or too small) for its type. Constants: a compile error. Variables: wraps around silently.
      
        
      wraparound
      Rolling past the top of a type back to its bottom, like an odometer.
      
        
      two's complement
      The way signed integers are stored: the top bit counts as a negative amount.
      
        
      Inf / NaN
      Special float values: infinity, and "Not a Number".
      
        
      panic: integer divide by zero
      The run-time stop when an integer is divided by a zero held in a variable.
      
        
      math package
      Go's standard toolbox of float functions and constants: Sqrt, Round, Pi, MaxInt64…
      
        
      Print / Println / Printf
      Print as-is; print with spaces and a newline; print a formatted form.
      
        
      format string
      The first argument of Printf: text with blanks.
      
        
      verb
      The letter after % in a format string, like %d or %s.
      
        
      flag
      A mark between % and the verb: - (lean left), 0 (pad with zeros), + (show the sign), # (Go syntax).
      
        
      width / precision
      In %8.3f, 8 is the width (cells) and 3 the precision (digits after the point).
      
        
      Sprintf / Errorf
      Fill in a format and return a string, or an error, instead of printing.
      
        
      %! jam
      What Printf writes when a blank and its argument don't match: %!d(string=Ana), %!s(MISSING), %!(EXTRA int=2).
      
        
      go vet
      The proof-reader: it finds suspicious code that still compiles, including every Printf jam.
      
        
      octal / hex / binary
      Base 8, base 16 and base 2 ways to write numbers: 0o10, 0xff, 0b1010.
