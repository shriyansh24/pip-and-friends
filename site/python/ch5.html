    Under the hood: what a loop really does
    
      
      
      The while check happens only at the top
      
      
      A common belief is that Python watches the rule all the time and jumps out the moment it turns False. It does not. The rule is checked once per lap, at the top. The body always finishes the lap it started:
      
      
      
      
      After line 3, n is 6 and the rule n < 3 is already False, but line 4 still runs. Only then does Pip go back up, check, and leave.
      
      
      for asks for "the next item" until there are none
      
      
      A for loop works with anything iterable: anything that can hand out its items one at a time. Strings hand out characters. A range hands out numbers. Lists, dictionaries and files (later chapters) are iterable too. Each lap, for asks for the next item and moves the loop variable onto it. When the items run out, the loop ends.
      
      
      range doesn't make all its numbers in advance
      
      
      A range stores just its start, stop and step, and works out each number when asked. So a range of a trillion numbers is instant to make and takes almost no memory:
      
      
      
      
      The loop variable is a normal name
      
      
      It keeps its last value after the loop ends. And changing it inside the body does not change the next lap, because for simply moves the tag to the next item:
      
      
      
        
      
        
      
      
      
      
      (If the range is empty, the loop never runs, so the loop variable is never given a value at all.)
      
      
      Shorthand: +=
      
      
      total += n means the same as total = total + n. There are matching -=, *= and others. You will see them everywhere in real code:
      
      
      
    
      
  
      

  
      
    Loop-else: the "no break happened" clause
    
      
      
      Python has a rare feature that surprises even experienced programmers: a loop can have an else. It runs when the loop finishes normally, meaning no break happened. If a break fires, the else is skipped.
      
      
      
      
      Look closely at the indentation: the else lines up with for, not with if. It belongs to the loop. It is handy for searches: "if I never found it, say so".
      
      
      A while loop can have one too. It runs when the rule becomes False:
      
      
      
      
      A good way to remember it: read loop-else as "no break". Use it sparingly: it is easy to misread as "if the loop never ran".
      
    
      
  
      

  
      
    In real programs: where loops live
    
      
      
        
        
      • Games run a "game loop": read the keys, move everything, draw the screen, repeat about 60 times a second until the player quits (a break).
        • 
        
      • Servers such as web servers sit in a while True: loop waiting for the next request. Ctrl+C is how developers stop them while testing.
        • 
        
      • Retrying: networks fail. Programs try again a few times, then give up. This one pretends the third try works:
        • 
      
      
      
      
      
        
        
      • Checking input exactly like ask_range.py: forms, menus and command-line tools all re-ask until the answer is usable.
        • 
        
      • Processing data: every line of a file, every row of a spreadsheet, every pixel of a picture. In Chapter 7 you will loop over lists, which is the most common loop of all.
        • 
        
      • Accumulators everywhere: shopping basket totals, word counts, high scores (the biggest so far) and building a web page piece by piece.
        • 
      
      
      
      Python also has built-in shortcuts for some patterns, which you will meet later: sum() adds up numbers and max() finds the biggest. Knowing the loop underneath means you understand what they do.
      
    
      
  
      

  
      
    Common wrong ideas
    
      
      
        
        
      • "range(5) includes 5." It doesn't: 0, 1, 2, 3, 4. Five numbers, ending one short of the stop.
        • 
        
      • "range(1, 10) gives 1 to 10." It gives 1 to 9. For 1 to 10 write range(1, 11).
        • 
        
      • "The while rule is checked after every line." Only at the top of each lap (see "Under the hood").
        • 
        
      • "break stops all the loops." It only leaves the loop it is directly inside. In a nested loop, the outer one carries on (Boss 2).
        • 
        
      • "continue means carry on to the next line." The opposite: it skips the rest of the body and goes back to the top.
        • 
        
      • "An infinite loop will harm my computer." It just keeps one program busy. Press Ctrl+C. (A loop that builds an ever-growing string can eventually use lots of memory, which is another reason to stop it.)
        • 
        
      • "I can use break anywhere to stop something." Only inside a loop. Anywhere else, the Proofreader refuses the whole file:
        • 
      
      
      
      
      
        
        
      • "Indentation is just for looks." In Python, indentation decides which lines are inside the loop. Moving print in or out of the body changes the program.
        •

    Words from this chapter
    
      
      
      
        
      loop
      Code that repeats a block of lines.
      
        
      iteration
      One lap of a loop: one run of its body.
      
        
      body
      The indented lines under a while or for line. They are what repeats.
      
        
      while
      A loop that repeats as long as its condition is True. The condition is checked before every lap.
      
        
      condition
      A True/False question, like lap <= 3.
      
        
      for
      A loop that takes each item of something iterable in turn.
      
        
      loop variable
      The name that changes each lap, like lap in for lap in …. When the body never uses it, programmers often call it _.
      
        
      range
      A run of whole numbers: range(start, stop, step). The stop is never included.
      
        
      iterable
      Anything a for loop can take items from one at a time: strings, ranges, and later lists and files.
      
        
      counter
      A name that goes up by one each time something happens.
      
        
      accumulator
      A name that collects a result across laps: a total, a count, a biggest-so-far or a growing string.
      
        
      infinite loop
      A loop whose condition never becomes False.
      
        
      KeyboardInterrupt
      What Python reports when you stop a program with Ctrl+C.
      
        
      break
      Leave the loop immediately.
      
        
      continue
      Skip the rest of this lap and go on to the next one.
      
        
      nested loop
      A loop inside the body of another loop.
      
        
      off-by-one error
      A loop that runs one lap too many or too few.
      
        
      trace table
      A table with a column per name and a row per lap, filled in by hand to predict what a loop does.
      
        
      IndentationError
      The spaces at the start of a line don't fit the structure, so Python can't tell what is inside what.
      
        
      TypeError
      A value of the wrong kind was used, like a string where range needs an int.
