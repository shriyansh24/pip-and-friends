three_lines.py

Pip says: I start at the top and go down. One line at a time. Never skipping, never shuffling.

    Under the hood: why one error stops everything
    
    
      
    Running a file has two phases. First Python reads the whole file and checks it is written correctly (the Proofreader). Only then does it run the lines, top to bottom (Pip). Both programs below have a problem on line 2:
    
      
    
        
    syntax_first.py
    Line 1 never ran. The missing quote was found while reading.
    
        
    name_later.py
    Line 1 ran and printed one. The unknown name was only found at line 2.
    
      
    
      
    print is a function
    
      
    A function is a named piece of code you call with parentheses. A call also hands back a result. print hands back None, Python's word for "no value":
    
      
    
    
    
  
    

  
    
    In real programs: output, error output, exit codes
    
    
      
    A running program has two output streams. Normal output goes to standard output (stdout); error messages go to standard error (stderr). The red text in the terminals came from stderr.
    
      
    Every program also ends with an exit code: 0 means success, anything else means failure. Scripts and test tools read it to decide what to do next.
    
      
    
    
    
  
    

  
    
    Common wrong ideas
    
    
      
      
        
    • "The quotes get printed." They don't. print("Hi") shows Hi.
      • 
        
    • "Python will understand what I meant." It won't. Print and print are different names.
      • 
        
    • "An error means I broke something." Nothing is damaged. Read the last line first, then the line number.
      •

    Words from this chapter
    
    
      
    
        
    program
    A file of instructions Python follows from top to bottom.
    
        
    statement
    One instruction, usually one line.
    
        
    string
    Text in quotes, like "Hello, world!".
    
        
    SyntaxError
    The code is not written in a form Python can read. Nothing runs.
    
        
    NameError
    The program used a name Python does not know.
    
        
    traceback
    The report Python prints when an error happens during the run.
