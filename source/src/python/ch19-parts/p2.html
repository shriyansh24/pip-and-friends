First tool: @property. It turns a method into something you read like an attribute, with no brackets. The method runs every time you read it.

    15
    
Why _celsius with an underscore? Python has no locked attributes. Instead it has naming conventions, plus one renaming trick.

    

      names.py

      

    

    

      
PUBLICself.owner
Part of the class's promise. Use it freely.

      
INTERNALself._log
One underscore: "this is inside stuff, it may change, please don't touch". Python does nothing; it's a note to humans.

      
MANGLEDself.__pin
Two underscores in front: Python renames it to _Vault__pin (the last line shows it). It stops subclasses from clashing by accident.

From outside the class, the name __pin doesn't exist any more.

    

      mangled.py

      

    

    

      
      
Pip says: Not a lock, just a different name. v._Vault__pin would still work. Use two underscores rarely; one is the everyday way to say "private".
