Pip has started a Robot Club, run from a tiny office. On the wall: one big whiteboard. On each desk: a member's own notebook.

Pip says: The club's name goes on the whiteboard, once, for everyone. My name goes in my notebook. Ada's goes in hers.

The Professor says: Classes work exactly like that office. In Chapter 15 every attribute went in the cookie's own notebook, with self.name = …. Today we use the cutter's whiteboard too.

2

A class attribute is written on the class: one copy, shared by every object made from it. An instance attribute is written on one object, in its own notebook.

3

Anything assigned directly inside the class body (not inside a method) is a class attribute.
