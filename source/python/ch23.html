Fetch says: I found the till room! But nobody had put ring_up in it yet. So I told you to rename the file. Sorry, wrong advice.

      

    

    

    
How to fix
Read the traceback bottom-up, like Chapter 9 taught. The last line says what failed. The three frames above it tell the story: main.py line 1 → till.py line 1 → stock.py line 1, which asks for a name from till, a file already on the trail. When the last line names a module that is already on the trail above it, that's a circle. The "consider renaming" hint is meant for files like Chapter 13's random.py, and Python 3.13 and 3.15 both print it here because till.py sits in the script's own folder. Ignore it: the cure is to break the circle (Panel 18).

    20
    
Ready to share your building? A shareable project comes with blueprints: a file called pyproject.toml that tells installers its name, version, what it needs and which commands it adds. Many projects also put the package inside a folder called src: the src layout.

    

    

      shopkit/pyproject.toml

    

    

      
[project]who and what
The name people install by, a version number, a one-line description, the oldest Python it supports, and dependencies: other packages pip should install with it (none here).

      
[project.scripts]new commands
shopkit = "shopkit.cli:main" means: create a terminal command shopkit that calls main() in the module shopkit.cli.

      
[build-system]which builder
The tool that turns the folder into an installable package. Here, setuptools. Others you'll meet: hatchling, flit-core, uv_build, poetry-core.

    

    
TOML is a simple settings format: [sections], then key = value lines. Python 3.11 and newer can read it with the standard library's tomllib.

    Part 5 · Time and moneydatetime, timedelta, zoneinfo, time, decimal, fractions, math, statistics
    

  
    
    34
    
    The store rents out tools. Chapter 13 counted days with date. A datetime is a date plus a time of day, and a timedelta is a length of time you can add or subtract.
    
    
    
      rental.py
    
      
    
    
    
    
    
      
      
    Pip says: datetime + timedelta = datetime. datetime − datetime = timedelta. strftime formats it with codes: %A weekday, %d day, %B month, %H:%M the clock. ISO format (2026-11-08) is the safe one for files and computers.
    
    
    
  
    

  
    
    35
    
    The store has a branch in Paris and one in New York. A datetime that knows its time zone is called aware; one that doesn't is naive. zoneinfo.ZoneInfo gives you real zones, summer time included.
    
    
    
      zones.py
    
      
    
    
    
    
    
      
      
    The Professor says: The +01:00 is the offset from UTC, the world's reference clock. 9:00 in Paris and 3:00 in New York are the same moment, so == says True. Zone names like "Europe/Paris" come from the tz database; on Windows you may need pip install tzdata.

    Under the hood: how an import really runs
    
    
      
      
    The four steps of import store.tools.saw
    
      
      
        
    1. Check the cache. Python looks in sys.modules, a dict from dotted names to module objects. If store.tools.saw is there, it's done. That is why Panel 5's second import printed nothing.
      2. 
        
    2. Parents first. To import store.tools.saw, Python first imports store, then store.tools, running each __init__.py once.
      3. 
        
    3. Find. A top-level name like store is searched for in every folder of sys.path, in order. A name inside a package is searched for only in that package's own __path__ (its folder). Finders also know about built-in modules such as sys, and about frozen ones.
      4. 
        
    4. Load. Python creates an empty module object, puts it in sys.modules straight away, then runs the file's code inside it. Putting it in first is what stops infinite loops in circular imports, and also what hands out half-built modules (Panel 15).
      5. 
      
    
      
    After loading, the room is also tied as an attribute of its floor: store.tools.saw becomes reachable as the attribute saw of the module store.tools. That's why line 6 of visit.py can walk the dotted path after a single import.
    
      
    Why -m changes sys.path[0]
    
      
    For python3 file.py, the first entry of sys.path is the file's folder. For python3 -m mod and for python3 -c "…", it is the current working folder (for -c it shows as an empty string). The -I and -P options, and the PYTHONSAFEPATH environment variable, leave that entry out.
    
      
    Relative imports are worked out from __package__
    
      
    from ..prices import x inside a module whose __package__ is store.tools means: drop one name from the end (store), then add prices. Too many dots for the address gives ImportError: attempted relative import beyond top-level package. python3 -m sets __package__ correctly; running by path sets it to None.

    How the editable install works
    
      
    pip install -e . asks the build backend (setuptools here) for an "editable wheel". Instead of copying your code into site-packages, it leaves a small pointer there (a .pth file or a tiny import hook) that sends import shopkit to src/shopkit. The console script shopkit is a small launcher file in .venv/bin (on Windows, .venv\Scripts\shopkit.exe) that imports shopkit.cli and calls main(). Editing a .py file takes effect at once; changing pyproject.toml (a new command, a new dependency) needs the install command again. The PEP that defined editable installs is PEP 660; the [project] table is PEP 621.
    
    
    
  
    

  
    
    In real programs: packages and the store's aisles at work
    
    
      
      
        
    • Almost every library you install is a package with subpackages: requests, pandas, django. Their __init__.py files act as front desks, so you can write import pandas as pd; pd.DataFrame without knowing which room DataFrame lives in.
      • 
        
    • Command-line tools are declared in [project.scripts]. When you pip install a tool like black or pytest, that table is where its command comes from.
      • 
        
    • Big applications run their entry point with python -m app, using a __main__.py, so relative imports work everywhere inside.
      • 
        
    • Circular imports are one of the most common problems as a project grows. Teams fix them by moving shared models or constants into their own module, so that imports flow one way: from high-level files down to basic ones.
      • 
        
    • Counter powers word counts, log summaries and "top 10" lists; defaultdict builds indexes and graphs (each node mapped to a list of neighbours); deque drives breadth-first searches and undo buffers; heapq powers task schedulers and shortest-path searches.
      • 
        
    • Shops and banks keep money in Decimal or in whole cents as ints, never in floats. Servers store times as aware UTC datetimes and convert for each user's zone.
      • 
        
    • secrets makes session tokens, password-reset links and API keys; random with a seed makes repeatable tests and simulations.
      • 
      
    
    
    
  
    

  
    
    Common wrong ideas
    
    
      
      
        
    • "A folder needs __init__.py to be importable." Not since Python 3.3: without it you get a namespace package (Panel 19). You still usually want one.
      • 
        
    • "Relative imports are shorter, so use them in scripts too." They only work in modules that belong to a package (Panel 8). Scripts use absolute imports.
      • 
        
    • "python3 -m store/main.py." -m takes a dotted name with no .py: python3 -m store.main.
      • 
        
    • "The error says rename the file, so the name must clash." In a circular import that hint is misleading (Panel 16). Check whether the last line names a module that is already on the trail of frames above it.
      • 
        
    • "Importing a module twice runs it twice." The second import just reads sys.modules (Panel 5).
      • 
        
    • "defaultdict(list())." It needs the machine, list, not a finished list (boss level).
      • 
        
    • "Checking if d[key]: on a defaultdict is harmless." It creates the key (Panel 31). Use in or get.
      • 
        
    • "Decimal(0.1) is exact." It is an exact copy of an inexact float (Panel 38). Pass a string.
      • 
        
    • "A datetime without a zone means UTC." It means "unknown". Naive and aware datetimes can't even be compared (Panel 36).
      • 
        
    • "random is random enough for passwords." It's predictable by design (Panel 46). Use secrets.
      • 
        
    • "A heap is a sorted list." Only index 0 is guaranteed to be the smallest; the rest are in a loose heap order. Pop repeatedly to get sorted order.

    Words from this chapter
    
    
      
    
        
    package
    A folder of modules that can be imported as one thing, usually with an __init__.py. The building.
    
        
    subpackage
    A package inside a package. A floor.
    
        
    module
    One .py file (Chapter 13). A room.
    
        
    __init__.py
    The file that runs when a package is first imported; marks the folder as a regular package and can re-export names. The front desk.
    
        
    __all__
    The list of names from package import * hands out.
    
        
    absolute import
    An import with the full dotted address from a sys.path folder: from store.prices import price_of.
    
        
    relative import
    An import that starts with dots, counted from the current package: . this package, .. its parent.
    
        
    __package__
    The package a module belongs to; None for a file run by its path.
    
        
    sys.modules
    Python's dict of every module already loaded (the import cache).
    
        
    python -m
    Run a module by its dotted name, found through sys.path, as __main__.
    
        
    __main__.py
    The file python -m package runs.
    
        
    isolated mode (-I)
    Start Python without the script's folder in sys.path, without PYTHON… environment variables and without user site-packages.
    
        
    circular import
    Two or more modules that import from each other while loading, so one gets a half-built module.
    
        
    partially initialized module
    A module that is in sys.modules but hasn't finished running its code.
    
        
    namespace package
    A package folder without __init__.py; it may be spread over several folders.
    
        
    pyproject.toml
    A project's blueprints: name, version, dependencies, commands and build backend.
    
        
    src layout
    Keeping the package inside a src folder so it can only be imported once installed.
    
        
    build backend
    The tool that turns a project into an installable package (setuptools, hatchling, uv_build, poetry-core…).
    
        
    editable install
    pip install -e .: install a project so imports point at its source folder.
    
        
    console script / entry point
    A terminal command created from [project.scripts] that calls a Python function.
    
        
    lazy import
    lazy import x (3.15): bind the name now, load the module at its first use.
    
        
    standard library
    The modules that come with every Python. The hardware store.
    
        
    Counter
    A dict subclass that counts things; missing keys count 0.
    
        
    defaultdict
    A dict that calls a machine (list, int…) to make a value for a missing key.
    
        
    deque
    A double-ended queue: fast to add and remove at both ends; can have a maxlen.
    
        
    ChainMap
    Several dicts searched in order, as one.
    
        
    datetime / timedelta
    A date with a time of day / a length of time.
    
        
    naive / aware datetime
    Without / with a time zone (tzinfo).
    
        
    UTC
    Coordinated Universal Time, the reference clock that time zones are measured from.
    
        
    Decimal
    An exact decimal number, for money. The price tag.
    
        
    Fraction
    An exact fraction, a top and a bottom whole number.
    
        
    heap
    A list arranged so the smallest item is always at index 0.
    
        
    bisect
    Finding the position for a value in a sorted list by halving the search.
    
        
    t-string
    t"…" (3.14): like an f-string, but gives a Template object with text and values kept apart.
