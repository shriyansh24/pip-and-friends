    Under the hood: copies, join, and what len really counts
    
      
      
      
      Why every method returns a new string
      
      
      A str object can never change after it is made (Chapter 7). So a method like upper() has no choice: it reads the old string, builds a new one, and hands that back. The old object is untouched. If no name or container points at it any more, CPython frees its memory straight away, which is what the faded boxes in the tracer show.
      
      
      Why join beats repeated +
      
      
      s = s + piece cannot grow s in place, so in general it builds a whole new string each time, copying everything collected so far. Over many pieces, that copying adds up. "".join(pieces) measures all the pieces first, then builds the result once. CPython can sometimes speed up += on strings behind the scenes, but the official style guide, PEP 8, says not to rely on it: use join when you build text in a loop.
      
      
      len counts code points
      
      
      len counts code points, Unicode's numbered characters. Most characters, including most emoji, are one code point. Some things you see as one symbol are made of several: a thumbs-up with a skin tone is the thumbs-up plus a skin-tone modifier, and a flag is two "regional indicator" letters.
      
      
      
      
      Bytes, encodings such as UTF-8, and making different spellings of "é" compare equal (normalization) all wait for Chapter 25.

      That is why tests_table.py in Panel 37 wrote !s: it turns the bool into the string "True" first, and text formatting keeps the word.
      
    
      
  
      

  
      
    In real programs: cleaning data, slugs, invoice numbers
    
      
      
        
        
      • Cleaning fields. Text from forms, spreadsheets and files almost always gets strip() and often casefold() before it is stored or compared. Usernames and e-mail addresses are classic examples.
        • 
        
      • Slugs. Blogs and shops turn titles into web-address pieces with chains like Panel 27's. Real slug code also removes punctuation, usually with the regular expressions of Chapter 25.
        • 
        
      • Fixed-width numbers. Invoice and ticket numbers use zero padding such as f"INV-{n:05d}", so they sort correctly as text.
        • 
        
      • Reports in the terminal. Command-line tools print tables exactly the way scoreboard.py does: one width per column, text left, numbers right.
        • 
      
      
      
      isdigit has small print
      
      
      isdigit() is a fine first check, but it is not a perfect promise that int() will succeed. It says no to a minus sign and a decimal point, and it says yes to a few special digit characters such as the superscript ², which int() rejects. isdecimal() is stricter.     Common wrong ideas
    
      
      
        
        
      • "s.strip() changes s." It hands you a copy. Write s = s.strip().
        • 
        
      • "find gives False when it misses." It gives -1, and in an if, every number except 0 counts as true. Worse, a match at carriage 0 counts as false:
        • 
      
      
      
      
      
        
        
      • "strip() removes all the spaces." Only at the two ends. To squeeze the inside gaps, split and join again.
        • 
        
      • "strip("abc") removes the word abc." It removes any of the characters a, b and c, as many as it finds at each end:
        • 
      
      
      
      
      
        
        
      • "split(" ") and split() are the same." Only when every gap is exactly one space. Panel 17 shows the difference.
        • 
        
      • "Width cuts long values to fit." Width is a minimum. Only a precision on text, like {s:.2}, cuts.
        • 
        
      • "lower() is the right way to ignore case." For English it works. For any language, use casefold().

    Words from this chapter
    
      
      
      
        
      escape sequence
      A backslash plus a character that stands for one special character, such as \n (new line) or \t (tab).
      
        
      raw string
      A string with r in front: backslashes stay plain backslashes.
      
        
      triple-quoted string
      A string in """ or ''' that can span several lines.
      
        
      method
      A function that belongs to an object, called with a dot: s.upper().
      
        
      attribute
      Anything you reach with a dot on an object. AttributeError means it isn't there.
      
        
      case
      Whether letters are capitals (upper case) or small letters (lower case).
      
        
      casefold()
      An extra-strong lower case for comparing text in any language.
      
        
      whitespace
      Invisible characters: spaces, tabs and new lines.
      
        
      strip()
      A copy without whitespace (or the listed characters) at both ends.
      
        
      empty string
      "" or '': a string with no characters, length 0.
      
        
      separator
      The text that split cuts at and that join glues between pieces.
      
        
      substring
      A piece of a string, such as "nan" in "banana".
      
        
      find() / index()
      The position of the first match; on a miss, -1 / ValueError.
      
        
      is-tests
      Methods such as isdigit() that answer True or False about every character.
      
        
      chain
      Several method calls in a row, each working on the previous copy.
      
        
      slug
      A lower-case, dashed version of a title, used in web addresses.
      
        
      code point
      The number Unicode gives a character. ord() and chr() convert.
      
        
      Unicode
      The worldwide numbered list of characters, from every alphabet to emoji.
      
        
      expression
      Any piece of code that works out to a value, such as qty * price.
      
        
      format spec
      The instructions after the colon in a hole: fill, align, width, grouping, precision, type.
      
        
      padding
      Extra characters (spaces unless you choose a fill) added to reach the width.
      
        
      repr() / !r
      The value written the way you'd type it in code, with quotes and escapes.
      
        
      str() / !s
      The plain, human view of a value, as print shows it.
