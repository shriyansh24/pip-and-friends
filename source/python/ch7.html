    Under the hood: what a list really stores
    
              
      
      
              A list does not hold its items "inside" the boxes. Each box holds a reference: an arrow to an object somewhere else in memory. The tracer draws small numbers and strings inline to keep the picture tidy, but they are references too. That is why one list can hold a mix of kinds, and why a list can hold another list.
              
      
              Negative indexes are arithmetic
              
      
              For a list of length n, index -k means index n - k. Python adds the length for you:
              
      
              
      
              Copies are shallow
              
      
              .copy() and [:] make a new outer list, but its boxes hold the same arrows as the original. With a grid, both lists point at the same inner rows:
              
      
              
      
              The append only touched the copy (a new outer box). But copy[0][0] = 99 walked into an inner row that both lists share. For a fully independent grid, use copy.deepcopy() from the copy module.
              
      
              Fast and slow changes
              
      
              CPython stores a list as one block of references in a row, with some spare room at the end. So append and pop() at the end are quick, while insert(0, x) and pop(0) must shift every other reference along by one. For small lists you will never notice. For a queue with thousands of items, the official tutorial recommends collections.deque.
              
      
              Why changers return None
              
      
              The official tutorial calls this "a design principle for all mutable data structures in Python": a method that changes an object in place returns None, so you can't confuse it with one that builds a new object. Compare sorted(x) (new list) with x.sort() (same list, returns None), and string methods like upper(), which always return a new string because strings can't change.
              
    
              
  
              

  
              
    In real programs: sorting with a key, splitting a line of data
    
              
      
              Sorting text: capitals come first
              
      
              Python sorts strings by character code, and every capital letter comes before every lowercase letter. Pass key= to sort by something else: str.lower ignores case, and len sorts by length.
              
      
              
      
              Notice key=len: words of equal length keep their original order. Python's sort is stable, which the docs guarantee.
              
      
              One line of a spreadsheet
              
      
              Data files often store one record per line, with commas between the fields (CSV). split(",") plus unpacking pulls a line apart in one go. Every field comes out as a string, so convert numbers yourself:
              
      
              
      
              Real CSV files can have quoted commas inside fields; for those, use the csv module from the standard library.
              
    
              
  
              

  
              
    Common wrong ideas
    
              
      
                
        
              • "The first item is number 1." It is index 0. The last is len(lst) - 1, or -1.
                • 
        
              • "lst[1:3] gives three items." It gives two: indexes 1 and 2. Stop is out.
                • 
        
              • "b = a copies the list." It adds a second tag to the same list. Use a.copy().
                • 
        
              • "Save the result of append." Changers return None, so the list is lost:
                • 
      
              
      
              
      
                
        
              • "Round brackets make a tuple." The comma makes the tuple. Brackets only group:
                • 
      
              
      
              
      
                
        
              • "join works on any list." Only on a list of strings. Convert numbers first:
                • 
      
              
      
              
      
                
        
              • "A tuple can never change, so nothing inside it can." A tuple's boxes are fixed, but if a box points at a list, that list can still change. Sealed means the arrows can't be swapped.

    Words from this chapter
    
              
      
              
        
              list
              An ordered, changeable row of items, written with square brackets: [1, 2, 3].
              
        
              item
              One thing stored in a list (also called an element).
              
        
              index
              A crate's position number, starting at 0. Negative indexes count from the back.
              
        
              IndexError
              The error for an index outside the row, or for pop() on an empty list.
              
        
              len()
              A built-in function that counts the items in a list, string or tuple.
              
        
              slice
              lst[start:stop:step]: a new list made from a run of items. Start is in, stop is out.
              
        
              mutable
              Can be changed after it is made. Lists are mutable.
              
        
              immutable
              Can never be changed. Strings, tuples, ints and floats are immutable.
              
        
              method
              A function that belongs to an object, called with a dot: lst.append(x).
              
        
              in
              An operator that asks whether a value is in a sequence; gives True or False.
              
        
              ValueError
              The right kind of value, but not one that works here, e.g. remove of a missing item.
              
        
              enumerate()
              Gives index and item together while looping.
              
        
              sorted() / .sort()
              A new sorted list / sort the same list in place (returns None).
              
        
              aliasing
              Two names for the same object.
              
        
              copy
              A new object with the same contents: lst.copy() or lst[:].
              
        
              sequence
              Any ordered collection you can index and slice: lists, strings, tuples.
              
        
              split() / join()
              String into list of strings / list of strings into one string.
              
        
              tuple
              An ordered, immutable row of items: (3, 4). The comma makes it.
              
        
              packing / unpacking
              Commas bundle values into a tuple / one name per item takes them out.
              
        
              reference
              The arrow from a name (or a list box) to an object.
