    Under the hood: what each creature really is
    
        
      
        Bricks are as long as they need to be
        
      
        A Python int is stored as a list of chunks of binary digits that grows as needed, so arithmetic on ints is always exact. Python 3.11 added one safety limit: turning an int with more than 4300 digits into text (with str() or print) is refused, because doing it for gigantic numbers is very slow and attackers could abuse that. The same limit applies the other way, from text to int (see Built-in types: integer string conversion length limitation). The maths itself has no such limit.
        
      
        
      
        Jelly is 64 bits of binary
        
      
        A float is an IEEE 754 "double": 64 bits holding about 15 to 17 significant decimal digits. Python prints the shortest decimal that maps back to the same stored value, which is why 0.1 looks clean until you ask for 20 digits. as_integer_ratio() shows the exact fraction really stored: a whole number divided by a power of 2. The same storage explains round(2.675, 2): the stored value is slightly below 2.675, so it rounds down.
        
      
        
      
        Lamps are secretly bricks
        
      
        bool is a special kind of int: True behaves as 1 and False as 0 in maths. Handy for counting, confusing if you do it by accident.
        
      
        
      
        There is exactly one ghost
        
      
        None is a single object shared by the whole program; every None is the very same one. Its type, NoneType, has no other values.
        
    
        
  
        

  
        
    Sharing below zero: // and % with negative numbers
    
        
      
        // is floor division: it always rounds down, toward minus infinity, never toward zero. For positive numbers the two are the same. For negative numbers they are not.
        
      
        
      
        
      
          
        
        • Python keeps one promise for every pair of numbers: (a // b) * b + a % b gives back a. Line 4 checks it for -17.
          • 
        
        • Because // floors, % always has the same sign as the divisor (the number after the %). So -17 % 5 is positive and 17 % -5 is negative.
          • 
        
        • Some languages (C, Java, JavaScript) chop toward zero instead, so their % on negatives gives different answers. Python's rule is handy for clocks and calendars: hour % 24 is never negative.
          • 
      
        
    
        
  
        

  
        
    In real programs: money, time and digits
    
        
      
        Because Jelly wobbles, programs that handle money avoid plain floats. Two common choices: count whole cents as an int, or use the decimal module, which stores decimal digits exactly. // and % turn cents into dollars and seconds into minutes.
        
      
        
      
          
        
        • {cents % 100:02d}: d means a whole number, 02 means "at least 2 wide, pad with zeros", so 5 cents shows as 05.
          • 
        
        • Rounding is for showing. Keep full precision while calculating, and round once at the end, with :.2f or round().
          • 
        
        • Whenever data arrives as text (keyboard, files, web forms), convert it at the door: int(...) or float(...), once, right where it comes in.
          • 
      
        
    
        
  
        

  
        
    Common wrong ideas
    
        
      
          
        
        • "int() rounds." It chops toward zero: int(3.9) and int(-3.9) both lose the fraction. Use round() to round.
          • 
        
        • "round() always rounds .5 up." Python rounds exact halves to the even neighbour, and some "halves" like 2.675 are stored a hair below half.
          • 
        
        • "Dividing two ints gives an int." / always gives a float in Python 3. Use // for a whole-number share.
          • 
        
        • "-3 ** 2 is 9." Power goes before the minus sign. Use brackets: (-3) ** 2.
          • 
        
        • "1,000,000 is a million." It is three separate numbers; use 1_000_000.
          • 
        
        • "bool("False") is False." Any non-empty text is True, whatever it says.
          • 
        
        • "None is the same as 0, "" or False." They are all "off" for bool(), but they are four different creatures.
          • 
        
        • "% means percent." It means remainder.
          • 
        
        • "input() gives a number if I type digits." It always gives a str. Convert it.
          •

    Words from this chapter
    
        
      
        
        
        type
        The kind of a value. It decides what operators and functions do with it. type(x) tells you.
        
        
        int
        Integer: a whole number, any size. Brick.
        
        
        float
        A number with a decimal point, stored in binary, a hair imprecise. Jelly.
        
        
        str
        String: text, a sequence of characters. Train.
        
        
        character
        One letter, digit, space or symbol: one carriage.
        
        
        bool
        Boolean: True or False. Lamp.
        
        
        None
        The single "no value" value, of type NoneType. Ghost.
        
        
        operator
        A symbol for a job: + - * / // % **.
        
        
        operand
        A value an operator works on.
        
        
        expression
        Code that Python works out to one value, like 2 + 3 * 4.
        
        
        precedence
        Who goes first: the stairs.
        
        
        floor division
        //: divide and round down to a whole number.
        
        
        remainder, modulo
        %: what is left over after floor division.
        
        
        exponent
        The power in **.
        
        
        binary
        Counting with only 0 and 1, the way computers store numbers.
        
        
        conversion
        Making a new value of another type: int(), float(), str(), bool().
        
        
        concatenation
        Joining strings with +.
        
        
        length
        The number of characters in a string: len().
        
        
        format spec
        The rules after : in an f-string slot, like .2f or ,.
        
        
        REPL
        The interactive >>> prompt.
        
        
        ValueError
        Right type, wrong value: int("3.9").
        
        
        TypeError
        Wrong type for the job: "Age: " + 30, len(42).
        
        
        ZeroDivisionError
        Dividing, floor-dividing or taking a remainder by zero.
